DAYFLOW — READY TO UPLOAD

FILES
- index.html: app page
- style.css: design and mobile responsiveness
- app.js: day counter and automatic local save

UPLOAD TO YOUR GITHUB REPOSITORY
1. Open https://github.com/farjiwala/Wantex-YT
2. Click Add file > Upload files.
3. Extract this ZIP on your device first.
4. Upload index.html, style.css, and app.js (README.txt is optional).
5. Click Commit changes.

OPTIONAL: PUBLISH WITH GITHUB PAGES
1. Open repository Settings > Pages.
2. If GitHub Pages is available for your repository/plan, choose Deploy from a branch.
3. Choose branch main and folder /(root), then Save.
4. Wait for GitHub to show the website link.

IMPORTANT
Progress saves in the same browser/device using localStorage. Clearing browser data, using private/incognito mode, or switching devices/browsers may remove or not carry over saved progress.
This ZIP does not access or change your GitHub repository automatically.
A private repository's GitHub Pages availability depends on your GitHub plan and repository settings.
